# ADR-0002. Отчёты из PostgreSQL в MVP

**Статус** — принято в v0.0.

Отчёт вычисляется из авторитетных наблюдений трекера. Счётчики выполнения берутся из заданий, а знаменатели метрик определяются outcome наблюдений. Для объёма MVP достаточно агрегатов PostgreSQL по tenant и run.

При реализации аналитики API будет читать отчёты через `ReportReader` с реализацией на PostgreSQL. Пока все записи и агрегаты находятся в одной БД, для завершённого запуска отчёт доступен сразу после финализации.

Альтернатива — сразу писать аналитическую проекцию в ClickHouse. Это дало бы отдельный контур аналитической нагрузки, но потребовало бы доставки изменений и учёта отставания проекции. При переходе к ClickHouse потребуется сверить обе реализации на одних и тех же запусках, включая эталонные выдачи из v0.0. PostgreSQL остаётся владельцем наблюдений.
